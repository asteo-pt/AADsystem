GitHub 연결

토큰은 저장하지 않아요. 새로고침하면 다시 입력해야 해요.

1기준사진등록

원본 사진은 저장 안 하고, 특징값(임베딩+통계)만 작은 JSON으로 리포에 저장돼요. 용량 걱정 없이 계속 늘릴 수 있어요.

실제 사진 추가

AI 생성 사진 추가
등록됨 0장

여기서 추가한 사진은 바로 특징값만 뽑히고 원본은 리포에 안 올라가요. 아래 "특징값 저장"을 눌러야 리포에 반영돼요.

예전에 올린 원본 사진 정리

real/fake 폴더에 예전 방식으로 올려둔 원본 사진이 있으면, 특징값으로 변환하고 원본은 지워서 용량을 돌려받을 수 있어요. 한 번만 하면 돼요.

2모델 학습

등록된 사진 특징으로 분류기를 이 자리에서 학습시켜요.

3모델 배포

학습된 모델을 리포의 model/ 폴더에 올려요. 공개 판별기(index.html)가 이 파일을 읽어서 모두가 같은 모델을 쓰게 돼요.
